# EurogreenPlus
This repository hosts **Eurogreen+**, an ecological macroeconomic model for Italy, developed by researchers at the Ecohesion Collective research group of the University of Pisa, as part of the EU Horizon projects MAPS and WISER.

The repository contains the model file in Vensim, a folder with associated data source files, the model documentation and a user guide to download the model and simulate the baseline scenario. `Vensim DSS` is required to run the model.
